# Finer

Finer is a browser-based personal finance dashboard for tracking income, expenses, mortgage and loan payments, savings goals, and financial health.

## Privacy and accounts

This is a static website. It does not create online accounts or send financial records to a server. Each visitor's profile and finance data are saved in that browser on that device. Data does not automatically sync between devices or browsers. The name and Gmail fields are local profile details, not sign-in credentials.

## Update the site

The website is in `index.html`. Changes published to the site's GitHub Pages source can update the public site automatically. Ask Codex to edit the local `index.html`, then publish the updated file to the same repository to keep the same website link.
